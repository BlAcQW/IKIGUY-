# Removed Common English Words from PREMIER_CITIES_MIN.md

This file documents the common English words that were removed from the Premier Health cities list to keep only actual Ghanaian location names.

## Summary
- **Original count**: 366 words
- **Removed**: 71 common English words
- **Remaining**: 295 actual location names
- **Date removed**: 2025-10-20

## Reasoning

These words were removed because they are:
1. Common English words that add noise to transcription keyword boosting
2. Generic descriptors rather than specific location names
3. Brand names or organization acronyms
4. Directional/positional terms commonly used in addresses

## Result

The cleaned list now contains only actual Ghanaian cities, towns, suburbs, and neighborhoods, improving the accuracy of speech recognition for location-specific queries in the Premier Health Navigator assistant.
